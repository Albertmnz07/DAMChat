<p>Servicio para alojar un servicio web para compartir notas de texto.</p>

<p>La parte importante es el back-end construido en Java, que levanta el servidor a partir de SpringBoot</p>
<p>El front-end se ha desarrollado rápidamente mediante Claude</p>

<p>La base de datos utilizada es Mysql</p>

<p>La idea es un sistema sencillo en el que cualquiera pueda crear, eliminar y modificar las notas</p>

<p>En un futuro se hará un sistema más desarrollado mediante control de usuarios y permisos sobre los recursos</p>
